# RestAInUp — Sito

Progetto React (Vite + TypeScript + Tailwind CSS v4 + Radix UI/shadcn).

## Comandi

Installa le dipendenze:

```
npm i
```

Avvia il server di sviluppo:

```
npm run dev
```

Genera la build di produzione:

```
npm run build
```

Rigenera `public/sitemap.xml` (aggiorna prima l'elenco pagine in `scripts/generate-sitemap.mjs`):

```
npm run sitemap
```

Deploy su GitHub Pages (branch `gh-pages`):

```
npm run deploy
```
